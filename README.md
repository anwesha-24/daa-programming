# 5th Semester DAA Programs in C

This repository contains C implementations of various algorithms studied in the **Design and Analysis of Algorithms (DAA)** course during the 5th semester of B.Tech CSE at KIIT. These programs are designed to provide hands-on understanding of algorithmic strategies, complexity analysis, and optimization techniques.

## Topics Covered

- Divide and Conquer Algorithms  
  - Merge Sort  
  - Quick Sort  
  - Binary Search  
- Greedy Algorithms  
  - Fractional Knapsack  
  - Job Sequencing  
  - Huffman Coding  
- Dynamic Programming  
  - 0/1 Knapsack  
  - Matrix Chain Multiplication  
  - Longest Common Subsequence  
- Backtracking  
  - N-Queens Problem  
  - Graph Coloring  
  - Hamiltonian Cycle  
- Graph Algorithms  
  - Dijkstra’s Algorithm  
  - Prim’s and Kruskal’s MST Algorithms  
  - Warshall’s and Floyd’s Algorithms  
- Branch and Bound  
  - 0/1 Knapsack  
  - Travelling Salesman Problem  
- Complexity Analysis and Comparison
